# mld_data_analysis
Python/Jupyter pipeline merging ORAS5, ERA5, and DUACS altimetry with Argo validation to characterize MLD climatology, trends, and driver attribution across three sub-basins (5–23°N, 80–100°E). Includes Theil-Sen trend analysis with autocorrelation correction, EOF decomposition, a spatially-blocked-CV GLM with explicit interaction terms.
