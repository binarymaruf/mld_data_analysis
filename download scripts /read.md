Python scripts for downloading and preprocessing the ocean and atmospheric datasets used in this study: ORAS5 ocean reanalysis, ERA5 atmospheric reanalysis, DUACS satellite altimetry, and Argo float profiles. Each script pulls from its native archive (Copernicus CDS, Copernicus Marine, GDAC), regrids to a common 0.25° analysis grid, and standardizes units and time indexing so the outputs merge cleanly into a single analysis cube. The Argo downloader is chunked and resumable to handle multi-decade requests without timing out.
